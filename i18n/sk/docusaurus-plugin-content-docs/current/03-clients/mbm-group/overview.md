# MBM-GROUP — Prehľad

Marketingová stránka mbmgroup.sk plus niekoľko menších statických stránok a prostredie SharePoint/M365. Živá stránka je Astro, bez backendu; interná administrácia pracovných ponúk (`mbm-kariera-admin`) je samostatná Electron aplikácia nad Supabase.

## Webstránky

Dve nezávislé statické stránky, každá vlastný git repozitár, každá nasadzovaná inak.

### [mbmgroup.sk](https://www.mbmgroup.sk)

- Statická stránka.
- Repozitár: [xNovakb/mbmgroup](https://github.com/xNovakb/mbmgroup) (súkromný)
- Panely na nasadenie/hosting:
  - [webpanel.sk](https://www.webpanel.sk/auth/login)
  - [iftp.sk](https://iftp.sk/index.php)

### [asfaltyrecyklacia.sk](https://www.asfaltyrecyklacia.sk)

- Statická stránka.
- Repozitár: [xNovakb/mbmgroup-asfalty](https://github.com/xNovakb/mbmgroup-asfalty) (súkromný)
- Hosting: Websupport, nasadenie cez ich hostingový panel.
- Panel na nasadenie: [webftp.asfaltyrecyklacia.sk](https://webftp.asfaltyrecyklacia.sk/)
