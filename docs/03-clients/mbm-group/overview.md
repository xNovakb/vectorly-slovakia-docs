# MBM-GROUP — Overview

mbmgroup.sk marketing site plus a few smaller static sites, and a SharePoint/M365 environment. Live site is Astro, no backend; internal job-posting admin (`mbm-kariera-admin`) is a separate Electron app over Supabase.

## Websites

Two independent static sites, each its own git repo, each deployed differently.

### [mbmgroup.sk](https://www.mbmgroup.sk)

- Static site.
- Repo: [xNovakb/mbmgroup](https://github.com/xNovakb/mbmgroup) (private)
- Deploy/hosting panels:
  - [webpanel.sk](https://www.webpanel.sk/auth/login)
  - [iftp.sk](https://iftp.sk/index.php)
